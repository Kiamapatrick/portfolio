# Portfolio Website

Personal portfolio website showcasing projects, skills, certifications, and blockchain experience.

## Features

- **About** - Personal background and experience
- **Projects** - Showcase of development projects
- **Skills** - Technical skills and expertise
- **Certifications** - Professional certifications
- **Blockchain** - Blockchain and Web3 experience
- **Contact** - Contact information and form

## Tech Stack

- HTML5, CSS3, JavaScript (Vanilla)
- Responsive design
- Modular CSS/JS architecture

## Structure

```
├── index.html          # Main landing page
├── about.html          # About page
├── projects.html       # Projects showcase
├── skills.html         # Skills overview
├── certifications.html # Certifications
├── blockchain.html     # Blockchain experience
├── contact.html        # Contact form
├── github.html         # GitHub profile
├── css/                # Stylesheets
├── js/                 # JavaScript modules
└── img/                # Images
```

## Local Development

Open `index.html` directly in a browser, or serve with a local server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx serve
```

## Deployment

Deploy to any static hosting service (GitHub Pages, Netlify, Vercel, etc.)
